# BizFlow

BizFlow is a full-stack web application designed to help small businesses 
centralize and manage their daily operations through a single, modern and 
secure interface.

## Features

- Client management
- Product and service catalog
- Order tracking with lifecycle management
- Payment recording and follow-up
- Role-based access control
- Activity logging
- Analytics dashboard

## Tech Stack

- **Frontend** — Next.js, React, TypeScript, TailwindCSS
- **Backend** — Next.js API Routes
- **Database** — PostgreSQL
- **DevOps** — Docker, Git
